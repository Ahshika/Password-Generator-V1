# Screenshots

Add two PNG files here for the main README:

| File | Content |
| --- | --- |
| `generator.png` | Password generator panel (length slider, options, generated password) |
| `vault.png` | Password vault panel (TOTP login or unlocked list) |

**How to capture**

1. Run `npm run dev` and open the app.
2. Take screenshots of both panels (or one full-window shot cropped into two images).
3. Save as `generator.png` and `vault.png` in this folder.

Until these files exist, GitHub may show broken image links in the README — that is expected until you add the files.
