## LinkedIn — Project description (English)

**NightGold Password Manager** — Desktop security utility I built with **Electron**, **React 19**, and **Tailwind CSS**.

The app combines a **customizable password generator** (length, character sets, optional Arabic letters) with a **local credential vault**. Saved passwords are stored in **SQLite**, encrypted with **AES-256-CBC**, and the vault is gated behind **TOTP two-factor authentication** (Speakeasy).

Highlights: bilingual **Arabic/English** UI with RTL support (i18next), secure Electron architecture (`contextIsolation`, preload IPC bridge), and **Windows NSIS** packaging via electron-builder.

Stack: Electron · React · Vite · Tailwind · SQLite3 · Node crypto · i18next

Repo: https://github.com/Ahshika/Password-Generator-V1

من أبرز ما في المشروع: واجهة **عربية/إنجليزية** مع RTL (i18next)، عزل Electron آمن (preload + contextIsolation)، وتعبئة **مثبّت Windows** عبر electron-builder.
